# SaveOnExit

<img src="logo.png" width="336" alt="the mod's logo" />

This is a Geometry Dash mod that automatically saves (backups) your save data to
RobTop servers whenever you exit and loads (syncs) your save data from RobTop
servers whenever you start the game.

That's it.

## AI
No AI has been used in the development of this mod.
